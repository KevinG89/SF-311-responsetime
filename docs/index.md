# Do lower-income neighborhoods wait longer for 311?

*UC Berkeley CP101, Fall 2026 · Shangrui Guo, Junhao Luo, Ryan Su*

This site will present our findings on how long San Francisco takes to close 311 service requests
in lower- versus higher-income census tracts, from 2020 to 2025:

- an interactive map of median waiting time by census tract
- an animated map of how waiting times changed year by year
- charts comparing waiting times by income group and request type

**Work in progress.** First results are planned for the midterm (November 2).

Data: SF 311 Cases (DataSF) and ACS 2020–2024 5-year estimates (IPUMS NHGIS).
Code and data pipeline: [GitHub repository]({{ site.github.repository_url }}).
